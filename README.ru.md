3. Запустите: `./MikuCode.AppImage`

## ✨ Возможности

### 💻 Программирование
- **Пишет код** — HTML, Python, JavaScript, любые файлы
- **Создаёт проекты** — папки, файлы, структура
- **Читает и редактирует** — работа с существующими файлами
- **Выполняет команды** — cmd, PowerShell (Windows) / bash (Linux)

### 🎵 Музыка для FL Studio
- **Генерирует MIDI** — мелодии, басы, аккорды, барабаны
- **Создаёт .flp** — из шаблона или пустышку
- **Управляет темпом** — BPM задаётся в запросе
- **Понимает ноты** — C4=60, A4=69, барабаны (kick=36, snare=38)

### 🧠 Память и контекст
- **Долговременная память** — `~/.mikucode/memory/*.md`
- **Навыки** — переиспользуемые SKILL.md
- **Сжатие истории** — экономия токенов
- **Сессии** — автосохранение и загрузка

### 🌍 Локализация
- **RU / EN** — переключение на лету через `/lang`
- **Модель отвечает** на языке пользователя
- **Всё сохраняется** — язык не сбрасывается между запусками

### 🔥 YOLO режим
- **Без подтверждений** — действует сразу
- **Без вопросов** — делает предположения
- **Авто-retry** — пробует альтернативы при ошибках
- **30 ходов** вместо 10

### 🎨 Интерфейс
- **Real-time подсказки** — введите `/`
- **Стрелки для выбора** — модели и провайдеры
- **Цветные рамки** — в стиле Kimi Code
- **Статус-строка** — лимиты, история, память, YOLO

## ⚡ Быстрый старт

### 1. Получите бесплатный API-ключ Groq
Зарегистрируйтесь на [console.groq.com](https://console.groq.com) — **без карты**.

### 2. Запустите MikuCode
- **Windows:** двойной клик по `MikuCode.exe`
- **Linux:** `./MikuCode.AppImage`

### 3. Вставьте ключ
При первом запуске приложение попросит ваш Groq API-ключ. Он сохранится в `~/.mikucode/config.json`.

### 4. Начните использовать
Введите `/help` для списка команд.

## 🎮 Команды

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку |
| `/model` | Выбор модели (стрелками) |
| `/provider` | Провайдеры: `select` / `add` / `remove` |
| `/fl` | FL Studio: `midi` / `flp` / `template` |
| `/sessions` | Список сессий, `load <id>` |
| `/settings` | Настройки (tempo, history, template) |
| `/thinking` | Уровень: `low` / `medium` / `high` |
| `/stats` | Полная статистика + лимиты |
| `/memory` | Память: `save <имя> <текст>` |
| `/skill` | Навыки: `create <имя> <описание>` |
| `/hook` | Показать активные хуки |
| `/permissions` | Режим: `default` / `plan` / `acceptEdits` / `bypass` |
| `/compact` | Сжать историю вручную |
| `/export` | Экспорт диалога в txt |
| `/lang` | Сменить язык: `ru` / `en` |
| `/yolo` | YOLO режим: `on` / `off` |
| `/clear` | Очистить экран |
| `/exit` | Выход (сохраняет сессию) |

## 🔥 YOLO режим

YOLO — режим **без подтверждений**. Агент выполняет всё сразу, не задаёт вопросов, не останавливается.

```
/yolo on    # Включить
/yolo off   # Выключить
```

**Что меняется:**
- Лимит ходов: 10 → 30
- Никаких уточняющих вопросов
- Автоматический retry при ошибках
- Модель действует, а не спрашивает

⚠️ **Опасно:** в YOLO-режиме модель может выполнить `del /f /q` без предупреждения. Используйте осторожно.

В статус-строке появится `🔥 YOLO`, пока режим включён. Настройка **сохраняется** в `~/.mikucode/config.json`.

## 🏗️ Структура данных

Все данные пользователя хранятся в `~/.mikucode/`:

```
~/.mikucode/
├── config.json         # Язык, модель, провайдер, настройки
├── memory/             # Фрагменты памяти (*.md)
├── skills/             # Навыки (SKILL.md)
├── sessions/           # Сохранённые сессии (*.json)
└── hooks/              # Хуки (*.py)
```

**Windows:** `C:\Users\<Вы>\.mikucode\`
**Linux:** `/home/<вы>/.mikucode/`

### Удаление
Удалите папку `~/.mikucode`. Всё — MikuCode portable.

## ❓ FAQ

**Q: MikuCode бесплатный?**
A: Да, 100% бесплатно. Без карты, без подписки, без скрытых лимитов.

**Q: Это open source?**
A: Нет, MikuCode закрытый. Распространяются только скомпилированные бинарники.

**Q: Как получить API-ключ?**
A: [console.groq.com](https://console.groq.com) → Sign up → API Keys → Create.

**Q: Работает на Linux?**
A: Да, AppImage-сборка в тестировании. macOS в планах.

**Q: Можно подключить Claude/GPT-4?**
A: Да, через `/provider add` — любой OpenAI-совместимый endpoint.

**Q: Где хранятся настройки?**
A: `~/.mikucode/config.json` (язык, модель, провайдер, YOLO).

**Q: Как удалить всё?**
A: Удалите папку `~/.mikucode`.

**Q: Почему Windows Defender ругается?**
A: Потому что .exe не подписан (подпись стоит ~$300/год). Нажмите "Подробнее" → "Выполнить в любом случае". Бинарник безопасен.

**Q: Может ли MikuCode заразить вирусом?**
A: Нет. MikuCode выполняет только те команды, которые вы (или AI от вашего имени) явно запросили. Все данные остаются локально. В сеть уходят только запросы к Groq API.

## ⚠️ Безопасность

MikuCode выполняет **любые** команды и записывает файлы **без подтверждения** (в режиме `default`). Это опасно, если вы не доверяете модели.

**Рекомендации:**
- Используйте `/permissions plan` для безопасного режима
- Не запускайте от имени администратора
- Не давайте доступ к системным папкам (`C:\Windows`)
- В YOLO-режиме — особая осторожность

### Что MikuCode отправляет в облако
- Ваши промпты (в Groq API для обработки)
- Результаты вызовов инструментов (содержимое файлов, вывод команд) — чтобы дать модели контекст
- **Больше ничего.** Никакой телеметрии, аналитики, трекинга.

### Что остаётся локально
- Config, память, сессии, навыки, хуки — всё в `~/.mikucode/`
- Ваш API-ключ — хранится локально в `config.json`
